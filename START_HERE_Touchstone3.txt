PUBLISHING / REQUIRED LINKS
1. Sign in to GitHub and create a public repository (for example: north-star-bakery-touchstone3).
2. Upload the CONTENTS of North_Star_Bakery_Touchstone3 to the repository root.
3. Open Settings > Pages. Select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish. Copy the actual repository URL and actual published Pages URL into the two link fields in the Word document.
5. Open the published site in a private/incognito browser window. Test all four navigation links, images, audio/video fallback text, and the Contact form.
